# Task Routing

## 若用户要：

- 解读政策 / 监管文件 → `skills/policy-brief/SKILL.md`
- 润色已有草稿 → `skills/formal-polish/SKILL.md`
- 生成报告大纲 → `skills/report-outline/SKILL.md`
- 报告转 PPT → `skills/ppt-outline/SKILL.md`

## 路由冲突处理

当用户请求的描述可能匹配多个 skill 时，按以下规则消歧：

| 用户意图关键词 | 路由到 | 说明 |
|---------------|--------|------|
| 政策理解 / 政策解读 / 监管文件分析 | policy-brief | 提取政策要点，输出结构化简报 |
| 语言润色 / 表达优化 / 正式化改写 | formal-polish | 保持原意，提升表达质量 |
| 报告结构 / 报告提纲 / 年报框架 | report-outline | 基于材料生成层级化提纲 |
| PPT / 幻灯片 / 逐页提纲 / 页级转化 | ppt-outline | 将内容转化为逐页 PPT 提纲 |
| 政策文件 → PPT（组合任务） | 先 policy-brief，再 ppt-outline | 先提炼事实与结构，再做 PPT 化转化；两个阶段之间保持事实边界，不引入原文不含的信息 |

## 混合意图路由表

以下覆盖常见混合/歧义任务的推荐路由和边界行为。

| 混合意图 | 推荐路由 | 边界说明 |
|---------|---------|---------|
| 政策文件做成 PPT（"把这份政策做成 PPT"） | 先 policy-brief，再 ppt-outline | 先提炼事实与结构（不得补造），再页级转化。中间产物保留 source basis、待核实事项和 uncertainty markers。 |
| 年报风险章节做成汇报 PPT | 先 report-outline，再 ppt-outline | 年报不是政策文件，不走 policy-brief。先基于披露材料搭建提纲，再做页级转化。年报数据仅覆盖该机构已披露范围，不得推广为行业整体判断。 |
| 润色同时要求调整结构 | 先判断主需求 | 若结构调整为主、润色为辅：走 report-outline，在提纲生成后可选加 formal-polish。若润色为主、仅微调句序：走 formal-polish。不得以润色名义暗中重构论证框架或新增事实。 |
| 只有二手转述的政策解读请求 | policy-brief（降级模式） | 无原文或链接时，不得做完整政策解读。输出"材料整理边界与需补证据清单"：标明当前转述可覆盖的有限内容、缺失的原始出处、必须补充的材料后再做正式解读。 |
| "结合我行情况""按我行管理层口径" | 边界警告 + 保守执行 | 不得模拟任何银行内部口径、内部审批偏好或内部术语标准。若用户未提供明确的内部材料或口径说明，只基于公开材料给出保守整理，并明确标注"以下基于公开材料整理，未包含非公开的内部口径"。 |
| 领导/管理层汇报版 | 按内容类型路由，强化结论先行 | 判断底层是政策（policy-brief）还是报告/年报（report-outline），再根据需要加 ppt-outline 或 formal-polish。管理层汇报版要求结论先行、篇幅精简、待核实事项不省略。不得因"领导要看"而编造数据、省略不确定标记或强化结论。 |

## 顺序传递规则

当任务需要多个 skill 顺序执行时，阶段间传递必须遵守以下规则：

1. **保留 source basis**：每个阶段的输出必须标明信息来源，下一阶段不得剥离来源标注。
2. **保留 uncertainty markers**：前阶段标为"待核实""需补充来源""基于现有材料初步判断"的内容，后续阶段必须原样保留或等价转写，不得通过格式转换消除不确定标记。
3. **保留待核实事项**：前阶段列出的待核实事项，后续阶段必须完整带入或显式标注已从何处获取验证。
4. **不引入新事实**：任何阶段不得添加原始输入材料中不存在的事实、数字、机构、政策依据、监管口径或内部判断。

## 材料不足时的降级行为

当用户请求的政策解读、报告提纲或 PPT 提纲缺乏必要的原始材料时：

| 缺失情况 | 降级行为 |
|---------|---------|
| 无政策原文、无链接、仅有口头描述或二手转述 | 输出"材料整理边界与需补证据清单"：列出当前转述可覆盖的有限内容、缺失的原始出处、以及正式解读前必须补充的材料。不得强行生成完整政策简报。 |
| 有原文但覆盖范围不完整 | 可输出保守版结构化简报，但必须明确标注材料覆盖边界，列出缺失章节或条款，并将相关判断标为"待核实"。 |
| 年报/研究材料只提供摘要而非原文 | 可基于摘要给出初步提纲，但必须标注"以下为基于摘要的初步框架，完整版需补充原文对应章节"。 |

## 若任务同时包含多个目标

优先顺序建议：

1. 先提炼事实和结构（policy-brief 或 report-outline）
2. 再生成提纲（report-outline 或 ppt-outline）
3. 最后做润色或 PPT 化（formal-polish 或 ppt-outline）

组合任务中，每个阶段应使用对应 skill 的规则。跨阶段传递时保持事实忠实度，不因格式转换而增减信息。
