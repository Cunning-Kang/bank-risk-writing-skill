# Case 05: formal-polish-tone-control

## 目标能力

`skills/formal-polish/SKILL.md` — 语气控制润色

## 测试目的

验证 skill 能否将含有情绪化、夸张化或媒体化表述的文本改写为正式、中性、克制的文本，且：
- 去除情绪化措辞
- 去除夸张表述
- 保留信息内核
- 不因去情绪化而丢失关键判断

## 输入材料状态说明

当前为占位状态。

待填入：一段 500–1500 字的文本，包含明显的情绪化、夸张化或媒体化表述（建议基于公开材料人工构造，模拟"宣传稿风格""评论稿风格"或"新闻稿风格"的文本）。

## 任务要求

1. 将输入文本改写为正式、中性、克制的书面文本
2. 去除情绪化、夸张化、媒体化表述
3. 保留原文中有价值的信息内核
4. 标注原文中哪些结论可能缺乏足够支撑

## 期望输出特征

- 情绪化词汇被替换为中性表述
- 夸张表述被降级为审慎表述
- 媒体化标题被替换为正式标题
- 事实性信息被保留
- 判断性信息被标注为判断（而非事实）
- 原文中缺乏支撑的结论被明确标注

## 不允许犯的错误

- 去情绪化的同时也去掉了有价值的判断
- 将原文的审慎判断进一步强化
- 保留原文中的媒体化标题或夸张措辞未做处理
- 新增原文未包含的事实或数据
- 改写后变得过于保守以至于丢失了原文的核心观点
- 产出空泛但"安全"的内容

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 改写后信息组织是否清晰 |
| 事实忠实度 | 有价值的信息是否被保留 |
| 风格合规性 | 情绪化/媒体化表述是否被有效去除 |
| 实用性 | 改写后是否适合正式工作场景 |
| 边界标注 | 缺乏支撑的结论是否被标注 |

## 当前样本状态

**占位** — 待填入包含情绪化/媒体化表述的文本样本。建议从公开媒体报道中选取与银行风险管理相关的评论文章，作为"需要去媒体化"的输入。
