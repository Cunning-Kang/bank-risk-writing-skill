# Case 07: report-outline-annual-report

## 目标能力

`skills/report-outline.md` — 年报场景报告提纲生成

## 测试目的

验证 skill 能否基于银行年报的公开风险管理章节，生成结构清晰、层级合理、与材料高度相关的报告提纲，且：
- 提纲来自输入材料，而非通用模板
- 每一级提纲都能指导实际写作
- 不出现泛泛而谈的"万能模板"章节

## 输入材料状态说明

当前为占位状态。

待填入：一家上市银行的公开年报中"风险管理"或"风险管理状况"相关章节内容（篇幅 3000–8000 字，可从巨潮资讯网或银行官网获取）。

## 任务要求

1. 基于输入的年报章节内容，生成结构化报告提纲
2. 提纲包含：推荐标题、核心结论/写作主线、一级提纲、二级展开建议、建议补充材料
3. 用户指定用途为"研究分析"或"部门汇报"
4. 风格偏向研究型

## 期望输出特征

- 一级标题有明确逻辑顺序（非泛泛罗列）
- 二级展开建议具体指向输入材料中的内容
- 建议补充材料部分指出了分析还需要的额外信息
- 提纲与输入材料高度相关，不是通用年报分析模板
- 核心结论/写作主线用 1–3 句话概括

## 不允许犯的错误

- 输出通用年报分析模板（如"一、公司概况 二、业务分析 三、财务分析 四、风险分析 五、结论与建议"），与输入材料无关
- 一级标题过于空泛（如"基本情况""相关分析"）
- 二级展开建议只是"分析XXX""研究XXX"，无具体指向
- 编造年报中未提及的风险类型或数据
- 堆砌无意义章节使提纲看起来更"完整"

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 提纲层级是否清晰，逻辑是否通顺 |
| 事实忠实度 | 提纲内容是否与输入材料高度相关 |
| 风格合规性 | 表述是否正式、审慎 |
| 实用性 | 提纲是否能直接指导后续写作 |
| 边界标注 | 是否指出了需要补充的材料 |

## 当前样本状态

**占位** — 待填入银行公开年报风险管理章节。建议选取大型上市银行的年报，从巨潮资讯网或银行官网投资者关系页面获取。
