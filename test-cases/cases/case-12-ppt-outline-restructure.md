# Case 12: ppt-outline-restructure

## 目标能力

`skills/ppt-outline/SKILL.md` — 长文重构为 PPT 提纲

## 测试目的

验证 skill 能否将一篇较长的文本（5000–10000 字）重构为 PPT 提纲，且：
- 有效做信息取舍，不是简单压缩
- 提炼出真正值得上 PPT 的内容
- 控制每页信息密度
- 区分"必须呈现""可选呈现""不应上 PPT"的内容

## 输入材料状态说明

当前为占位状态。

待填入：一篇 5000–10000 字的长文（建议使用完整的公开研究报告、或合并多份公开材料的综合文本）。

## 任务要求

1. 将长文本重构为 PPT 页级提纲
2. 目标页数 6–10 页
3. 重点在于取舍判断——什么该上 PPT，什么不该
4. 每页保持聚焦，不堆砌
5. 明确列出"不建议上 PPT"的内容

## 期望输出特征

- 页数控制在目标范围内
- 选取的内容是最有汇报价值的部分，而非面面俱到
- "不建议上 PPT"列表内容丰富，说明做了认真取舍
- 每页信息密度适中（3–5 个支撑点）
- 页标题观点化
- 整体逻辑从结论到支撑到建议

## 不允许犯的错误

- 试图把长文所有内容都搬上 PPT
- 取舍标准不清晰，保留了过多细节
- 每页支撑点超过 7 个
- 页标题为目录式而非观点化
- "不建议上 PPT"部分为空或过于简略
- 编造原文中未包含的信息

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 取舍是否合理，逻辑是否连贯 |
| 事实忠实度 | 选取的内容是否忠实于原文 |
| 风格合规性 | 页标题是否观点化，整体是否可讲述 |
| 实用性 | 提纲是否真正适合 PPT 汇报 |
| 边界标注 | 取舍理由是否清晰 |
