# Case 08: report-outline-multi-source

## 目标能力

`skills/report-outline.md` — 多源材料场景报告提纲生成

## 测试目的

验证 skill 能否基于多份不同来源的公开材料，整合信息并生成统一的报告提纲，且：
- 有效整合不同来源的信息
- 提纲不偏向单一材料
- 对来源间矛盾或不一致之处做标注
- 生成逻辑连贯的整体结构

## 输入材料状态说明

当前为占位状态。

待填入：2–3 份与同一主题相关的公开材料（建议选取同一政策的不同解读视角，或同一风险主题的不同研究摘要）。每份材料 1000–3000 字。

## 任务要求

1. 基于 2–3 份输入材料，生成统一报告提纲
2. 整合不同来源的信息
3. 如有矛盾或不一致，明确标注
4. 提纲结构服务于整体分析，而非分别罗列各材料的要点

## 期望输出特征

- 提纲反映了对多份材料的整合，而非简单的材料 A 要点 + 材料 B 要点
- 一级标题围绕核心主题展开，而非按材料来源分章节
- 对材料间的差异或矛盾做了标注
- 建议补充材料部分指出了整合分析还需要的额外信息
- 写作主线清晰

## 不允许犯的错误

- 按材料来源分章节（如"一、材料 A 分析 二、材料 B 分析"），而非按主题整合
- 忽略材料间的矛盾或差异
- 将某一份材料的观点作为总体结论
- 编造材料中未提及的信息以"补齐"分析
- 输出过于冗长或重复

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 是否做到了真正的信息整合 |
| 事实忠实度 | 是否忠实于每份材料的内容 |
| 风格合规性 | 表述是否正式、审慎 |
| 实用性 | 提纲是否适合作为综合分析的写作框架 |
| 边界标注 | 材料间的差异是否被标注 |

## 当前样本状态

**占位** — 待填入 2–3 份与同一主题相关的公开材料。建议选取同一政策的官方解读 + 券商研究摘要 + 媒体公开评论，模拟多源整合场景。
