# Case 04: formal-polish-basic

## 目标能力

`skills/formal-polish.md` — 基础正式润色

## 测试目的

验证 skill 能否将一份口语化或半正式的草稿改写为更正式、更审慎、更适合正式工作场景的文本，且：
- 提升表达质量
- 不改变原意
- 不新增用户未提供的事实
- 去除口语化、泛化、空泛表述

## 输入材料状态说明

当前为占位状态。

待填入：一段 500–1500 字的口语化或半正式草稿（建议基于公开材料人工构造，模拟常见的工作草稿风格：口语化、松散、部分表述不够准确）。

## 任务要求

1. 将输入草稿改写为正式、审慎的书面文本
2. 保留原意，不擅自添加信息
3. 输出包含：修改方向说明、修订稿、待核实提示（如有）

## 期望输出特征

- 表述从口语化变为书面化
- 语气从绝对化变为审慎化
- 去除重复和冗余
- 保留原文中的所有关键信息
- 对原文中可能需要核实的数据或引用做出提示
- 不出现原文未包含的新事实、数字或出处

## 不允许犯的错误

- 新增原文中未提及的事实、数字或出处
- 将原文的审慎表述改写为更强结论
- 为了"显得专业"堆砌复杂词语
- 改变原文的核心意思
- 遗漏原文中的重要信息
- 写成新闻稿或营销稿风格

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 改写后逻辑是否更清晰 |
| 事实忠实度 | 是否严格保留原意 |
| 风格合规性 | 是否足够正式、审慎 |
| 实用性 | 改写后是否可直接用于正式文稿 |
| 边界标注 | 是否标出了原文中需要核实的部分 |

## 当前样本状态

**占位** — 待填入基于公开材料构造的工作草稿样本。建议参考公开年报或政策材料，人工改写为口语化版本作为输入。
