# Case 09: report-outline-insufficient-input

## 目标能力

`skills/report-outline/SKILL.md` — 输入不足场景的保守输出

## 测试目的

验证 skill 在输入材料明显不足以支撑完整报告提纲时，能否：
- 诚实标注当前材料能支撑的范围
- 不为"显得完整"而堆砌无意义章节
- 仍然提供基于现有材料的初步框架
- 明确指出需要补充什么材料

## 输入材料状态说明

当前为占位状态。

待填入：一份信息量明显不足的材料（建议使用仅有 200–500 字的简短摘要或片段，无法支撑完整的分析报告提纲）。

## 任务要求

1. 基于有限的输入材料，生成初步报告提纲
2. 明确标注提纲只能做到初步框架
3. 指出需要补充哪些材料才能完善
4. 不为"显得完整"而堆砌章节

## 期望输出特征

- 输出中明确出现"当前材料仅能支撑初步框架"等类似标注
- 提纲章节数量有限，与材料信息量匹配
- "建议补充材料"部分内容具体，指明了缺什么
- 不出现材料无法支撑的章节或分析维度
- 整体态度保守，不过度承诺

## 不允许犯的错误

- 输出一个看起来完整但大部分章节与材料无关的"万能模板"
- 编造材料中未提及的信息以填充章节
- 未标注材料不足的事实
- "建议补充材料"部分写得很空泛，无法指导实际补充
- 提纲结构看起来完整但每个章节下没有实质内容指向

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 提纲范围是否与材料信息量匹配 |
| 事实忠实度 | 是否严格限定在材料范围内 |
| 风格合规性 | 保守态度是否到位 |
| 实用性 | 是否清楚告诉用户下一步该补充什么 |
| 边界标注 | 这是最关键的评分维度——是否诚实标注了所有不足 |

## 当前样本状态

**占位** — 待填入信息量不足的简短公开材料。建议使用仅有几句话的新闻摘要或政策片段。
