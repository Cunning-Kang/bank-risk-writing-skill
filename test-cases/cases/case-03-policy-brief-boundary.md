# Case 03: policy-brief-boundary

## 目标能力

`skills/policy-brief.md` — 材料不足场景下的边界控制

## 测试目的

验证 skill 在输入材料不完整、信息模糊或仅有摘要片段的情况下，能否：
- 诚实标注材料不足的部分
- 不用猜测填补信息空白
- 对不确定内容使用审慎措辞
- 仍然提供基于现有材料的保守版结果

## 输入材料状态说明

当前为占位状态。

待填入：一份不完整的政策信息（建议使用仅有摘要、新闻通稿或部分章节的政策片段，而非完整原文，篇幅 500–1500 字）。

## 任务要求

1. 基于不完整输入材料，生成政策摘要
2. 明确标注哪些信息是缺失的
3. 对无法确认的内容使用"从当前材料看""有待结合后续规则进一步判断"等措辞
4. 不要用猜测补齐缺失信息

## 期望输出特征

- 输出中明确出现"材料不足""待补充"等标注
- 对缺失信息的处理方式是标注而非猜测
- 仍提供基于已有材料的结构化输出
- 不出现输入材料中未包含的具体信息
- 使用审慎措辞表达不确定性

## 不允许犯的错误

- 编造输入材料中未提及的政策条款或数字
- 输出看起来像材料充分，未做任何不足标注
- 对模糊信息做了过度解读
- 未区分"已知信息"和"推断信息"
- 输出结构与完整材料场景的输出无差异（应更保守）

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 是否在不完整信息下仍提供了有用结构 |
| 事实忠实度 | 是否严格限定在已知材料范围内 |
| 风格合规性 | 审慎措辞是否到位 |
| 实用性 | 是否清楚告诉用户还需要补充什么 |
| 边界标注 | 这是最关键的评分维度——是否诚实标注了所有不确定和缺失信息 |

## 当前样本状态

**占位** — 待填入不完整的公开政策信息片段。建议使用仅有新闻通稿或摘要的政策材料，模拟"信息不充分"的真实工作场景。
