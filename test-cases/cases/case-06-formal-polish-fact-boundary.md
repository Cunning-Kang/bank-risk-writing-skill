# Case 06: formal-polish-fact-boundary

## 目标能力

`skills/formal-polish.md` — 事实边界控制

## 测试目的

验证 skill 在润色过程中能否严格守住事实边界：
- 不新增用户未提供的事实、数字、出处
- 不将模糊判断改写成强结论
- 当原文信息不足时，不使用想象补齐
- 明确标注需要核实的部分

## 输入材料状态说明

当前为占位状态。

待填入：一段 500–1500 字的草稿，其中包含：
- 若干具体数字但未注明来源
- 若干判断性表述但缺乏支撑
- 若干政策引用但未写明具体文件名或文号
- 若干"似乎是对的但无法从文本中验证"的表述

## 任务要求

1. 对输入草稿做正式润色
2. 对无来源的数字，保留但标注"待核实"
3. 对缺乏支撑的判断，降级为审慎表述或标注"需补充依据"
4. 对未写明的政策引用，标注"建议补充具体文件名/文号"
5. 不自行补充缺失信息

## 期望输出特征

- 所有润色后的数字均有"待核实"标注或已确认有来源
- 缺乏支撑的判断被降级或标注
- 政策引用处有补充提示
- 输出中不出现原文未包含的具体数字或出处
- 待核实提示部分内容充实，逐条列出

## 不允许犯的错误

- 自行编造数字的来源或出处
- 将"大约""可能"类表述改写为确定表述
- 为原文的模糊引用自行补充具体文件名或文号
- 遗漏标注无来源数字
- 把原文的推测性判断改写成事实陈述

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 修订稿和待核实提示是否分离清楚 |
| 事实忠实度 | 是否严格不新增任何未提供的事实 |
| 风格合规性 | 审慎措辞是否到位 |
| 实用性 | 待核实提示是否足够具体，能指导后续工作 |
| 边界标注 | 这是最关键的评分维度——所有需要核实的信息是否都被标注 |

## 当前样本状态

**占位** — 待填入含有"数字无来源、判断缺支撑、引用缺出处"特征的草稿样本。建议基于公开年报或政策材料，人工构造一份信息不完整的工作草稿。
