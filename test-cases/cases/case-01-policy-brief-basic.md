# Case 01: policy-brief-basic

## 目标能力

`skills/policy-brief.md` — 基础政策摘要生成

## 测试目的

验证 skill 能否将一篇公开政策原文整理为结构清晰、表述审慎的政策摘要，且：
- 忠实提炼核心内容
- 区分事实与判断
- 不编造政策要求或实施细节
- 输出结构符合 policy-brief 的默认输出格式

## 输入材料状态说明

当前为占位状态。

待填入：一篇完整的公开政策或监管文件原文（建议选取近 1–2 年内发布的正式通知或办法，篇幅 3000–8000 字）。

来源建议：国家金融监督管理总局官网、人民银行官网或其他公开监管机构网站。

## 任务要求

1. 基于输入的政策原文，生成结构化政策摘要
2. 输出包含：文件概况、核心要点、可能影响、后续关注点
3. 风格正式、审慎、中性
4. 对不确定内容使用审慎措辞

## 期望输出特征

- 包含明确的文件概况（主题、性质、发文机构）
- 核心要点分条列出，每条对应原文的具体内容
- 可能影响部分基于材料分析，不超出材料范围
- 后续关注点标出需要进一步确认的内容
- 不出现输入材料以外的具体数字、日期或机构名称

## 不允许犯的错误

- 编造政策原文中未提及的要求或条款
- 将"建议""鼓励"类表述升级为"必须""要求"
- 漏掉原文中的关键变化或新增要求
- 使用媒体化标题或宣传腔表述
- 对材料未覆盖的范围做出确定性判断

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 是否遵循了文件概况→核心要点→可能影响→后续关注点的结构 |
| 事实忠实度 | 每个要点是否都能在原文中找到对应 |
| 风格合规性 | 表述是否正式、审慎、无媒体腔 |
| 实用性 | 摘要是否足够支撑后续研究或汇报 |
| 边界标注 | 是否标注了需要进一步核实的内容 |

## 当前样本状态

**占位** — 待填入真实公开政策文本。建议优先选取涉及银行风险管理或资本管理相关的正式文件。
