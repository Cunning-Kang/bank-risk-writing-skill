# Case 01: policy-brief-basic

## 目标能力

`skills/policy-brief/SKILL.md` — 基础政策摘要生成

## 测试目的

验证 skill 能否将一篇公开政策原文整理为结构清晰、表述审慎的政策摘要，且：
- 忠实提炼核心内容
- 区分事实与判断
- 不编造政策要求或实施细节
- 输出结构符合 policy-brief 的默认输出格式

## 输入材料

### 输入类型

bounded-input（受限输入）— 使用已有样本元数据引用作为材料参照，非 test-ready。

### 输入来源

- 元数据路径：`examples/policy/国家金融监督管理总局办公厅中国人民银行办公厅关于印发《银行业保险业普惠金融高质量发展实施方案》的通知.meta.yaml`
- 材料性质：国家金融监督管理总局与中国人民银行联合发布的公开政策实施方案
- 来源机构：国家金融监督管理总局、中国人民银行
- 内容范围：普惠金融高质量发展的实施方案（背景-目标-任务-保障结构）

### 来源边界

- 本材料为特定版本的公开政策文件，仅作为该版本文件的结构和表述参考。
- 政策可能已有后续修订或补充，引用前须核对最新正式文本。
- 当前 source_url 和 access_date 缺失，本 case 标记为 **bounded-input**，不标记为 test-ready。
- 运行本 case 时，评审者应向 skill 提供该政策文件的公开原文（可从国家金融监督管理总局官网获取），或将本 case 用于对已有 skill 输出的回溯评审。

### 材料引用方式

本 case 不在 case 文件中嵌入政策全文。运行方式：

1. **方式 A（推荐）**：评审者从国家金融监督管理总局官网或中国人民银行官网获取该文件的最新正式文本，将全文或核心章节作为 skill 输入。
2. **方式 B**：评审者使用已有 skill 对该政策生成的输出，对照 `test-cases/expected/case-01.expected.md` 验收。

## 任务要求

1. 基于输入的政策原文，生成结构化政策摘要
2. 输出包含：文件概况、核心要点、关键变化或重点关注、可能影响、后续关注点 / 待核实事项
3. 风格正式、审慎、中性
4. 对不确定内容使用审慎措辞
5. 区分已披露事实、基于材料的判断、可能影响、建议行动

## 期望输出特征

- 包含明确的文件概况（主题、性质、发文机构）
- 核心要点 3–8 条且每条可回溯至政策原文
- 可能影响部分基于材料分析，不超出材料范围
- 后续关注点 / 待核实事项至少 2 条，覆盖材料未明示的信息
- 不出现输入材料以外的具体数字、日期或机构名称

## 不允许犯的错误

- 编造政策原文中未提及的要求或条款
- 将"建议""鼓励"类表述升级为"必须""要求"
- 漏掉原文中的关键变化或新增要求
- 使用媒体化标题或宣传腔表述
- 对材料未覆盖的范围做出确定性判断
- 在没有对比依据时使用"新变化""明显收紧""重大调整"等确定性变化表述

## 人工评分重点

| 维度 | 关注点 |
|------|--------|
| 结构合理性 | 是否遵循了文件概况→核心要点→可能影响→后续关注点的结构 |
| 事实忠实度 | 每个要点是否都能在原文中找到对应 |
| 风格合规性 | 表述是否正式、审慎、无媒体腔 |
| 实用性 | 摘要是否足够支撑后续研究或汇报 |
| 边界标注 | 是否标注了需要进一步核实的内容 |

## Out of Scope

- 不验证政策本身的正确性或时效性
- 不验证 skill 是否捕捉了该政策后续修订的内容
- 不要求输出包含对行业影响的具体数值预测
- 本 case 不用于验证 skill 对多文件交叉引用的能力
