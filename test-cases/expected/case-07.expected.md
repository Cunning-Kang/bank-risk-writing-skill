# Case 07 Expected: report-outline-annual-report

## 期望输出结构

输出必须包含以下五段（顺序可微调，但五段均须出现）：

1. **推荐标题** — 明确主题和任务对象，不空泛（如包含年报主体名称、年度、聚焦范围）
2. **核心结论 / 写作主线** — 1–3 句说明全文围绕什么逻辑展开
3. **一级提纲** — 4–6 个一级部分，各章附作用说明（不能只有标题）
4. **二级展开建议** — 对每个一级部分至少说明：
   - 本节要写什么（写作任务）
   - 关键证据或数据来源是什么
   - 哪些地方需要审慎表述或标注边界
5. **建议补充材料** — 指出要写得更扎实还需要补哪些公开证据、数据或对照材料

## 期望出现的关键特征

- 推荐标题反映具体年报主体和聚焦范围，非泛泛"XX银行年报分析"
- 一级标题数量在 4–6 范围内，有明确逻辑顺序（如背景→内容→影响→建议），无重复
- 每个一级部分的作用用至少一句话说明，而非仅列标题
- 二级展开建议中，每个一级部分下至少包含 3 项具体写作指引（写什么 / 关键证据 / 审慎之处三维度中至少覆盖两项）
- 提纲内容可溯源至输入材料中的具体章节或数据，不是通用年报分析框架
- 建议补充材料列出至少 2 项具体缺失信息类型（如"同业对比数据""历史趋势数据""政策原文"）
- 如输入材料对某些分析维度支撑不足，对应位置有边界标注（如"该部分判断需结合后续数据进一步确认"）

## 不应出现的问题

- 输出通用年报分析模板（如"一、公司概况 二、业务分析 三、财务分析 四、风险分析 五、结论与建议"），与输入材料内容脱节
- 一级标题过于空泛（如"基本情况""相关分析""综合评价"），看不出写作任务
- 二级展开建议只写"分析XXX""研究XXX""讨论XXX"，无具体写作方向
- 编造年报中未提及的风险类型、数据指标或管理举措
- 堆砌与材料弱相关的章节以显得"系统完整"
- 一级标题之间内容重叠或逻辑顺序混乱
- 建议补充材料部分只写"补充更多资料"，无具体指向

### 高风险错误触发条件（本 case 特化）

| 高风险错误类型 | 本 case 触发条件 |
|----------------|------------------|
| 编造事实 | 输出中出现输入材料未包含的具体数字、指标名称、风险分类或管理动作 |
| 编造政策口径 | 模拟了年报材料中未提及的监管要求或内部标准 |
| 越界推断 | 将年报中的趋势性描述升级为确定结论（如将"有所上升"写成"显著恶化"） |
| 空泛建议 | 建议措施仅含"加强重视""持续推进""统筹做好"等，无具体行动方向 |
| 漏标不确定性 | 输入材料对某分析维度支撑不足，但输出未做任何标注 |

## 验收口径

| 条件 | 判定 | 检查方式 |
|------|------|----------|
| 五段结构完整存在 | 必须通过 | 逐段确认存在 |
| 一级提纲数量 4–6 个，各有作用说明 | 必须通过 | 计数 + 逐条检查是否有说明句 |
| 二级展开至少覆盖"写什么"和"关键证据/审慎"两个维度 | 必须通过 | 逐节抽样检查 |
| 提纲内容可溯源至输入材料 | 必须通过 | 抽查 ≥3 个二级条目，确认与材料对应 |
| 无编造事实/数据/政策 | 必须通过 | 抽查所有具体数字、指标、机构名是否材料中有出处 |
| 建议补充材料 ≥2 项且具体 | 必须通过 | 计数 + 检查是否有具体指向 |
| 一级标题无空泛命名 | 建议通过 | 检查是否每个标题都能暗示写作任务 |
| 核心结论/写作主线 ≤3 句 | 建议通过 | 计数 |
