# Case 07 Expected: report-outline-annual-report

## 期望输出结构

1. 推荐标题
2. 核心结论 / 写作主线（1–3 句）
3. 一级提纲（按逻辑顺序排列）
4. 二级展开建议（每节说明应写什么、重点放什么）
5. 建议补充材料

## 期望出现的关键特征

- 推荐标题明确反映材料主题，不空泛
- 一级标题有明确逻辑顺序（非泛泛罗列）
- 二级展开建议具体指向输入材料中的内容
- 建议补充材料部分指出了分析还需要的额外信息
- 提纲与输入材料高度相关，不是通用年报分析模板

## 不应出现的问题

- 输出通用年报分析模板（与输入材料无关）
- 一级标题过于空泛
- 二级展开建议只是"分析XXX""研究XXX"而无具体指向
- 编造年报中未提及的风险类型或数据
- 堆砌无意义章节

## 验收口径

| 条件 | 判定 |
|------|------|
| 提纲与材料高度相关 | 必须通过 |
| 二级建议有具体指向 | 必须通过 |
| 无编造信息 | 必须通过 |
| 建议补充材料具体 | 建议通过 |
