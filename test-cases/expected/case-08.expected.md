# Case 08 Expected: report-outline-multi-source

## 期望输出结构

1. 推荐标题
2. 核心结论 / 写作主线
3. 一级提纲（按主题整合，非按来源分章）
4. 二级展开建议
5. 来源差异标注（如有矛盾或不一致）
6. 建议补充材料

## 期望出现的关键特征

- 一级标题围绕核心主题展开，而非按材料来源分章节
- 提纲反映了对多份材料的整合
- 来源间的差异或矛盾被标注
- 写作主线清晰
- 建议补充材料部分指出了整合分析还需要的额外信息

## 不应出现的问题

- 按材料来源分章节（如"一、材料 A 分析 二、材料 B 分析"）
- 忽略材料间的矛盾或差异
- 将某一份材料的观点作为总体结论
- 编造材料中未提及的信息

## 验收口径

| 条件 | 判定 |
|------|------|
| 做到了真正的信息整合 | 必须通过 |
| 来源差异被标注 | 必须通过 |
| 无编造信息 | 必须通过 |
| 提纲逻辑连贯 | 必须通过 |
