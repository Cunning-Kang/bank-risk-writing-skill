# Case 08 Expected: report-outline-multi-source

## 期望输出结构

输出必须包含以下五段（顺序可微调，但五段均须出现）：

1. **推荐标题** — 明确主题和任务对象，体现多源整合后的统一视角
2. **核心结论 / 写作主线** — 1–3 句说明全文围绕什么逻辑展开
3. **一级提纲** — 4–6 个一级部分，按主题整合（禁止按来源分章），各章附作用说明
4. **二级展开建议** — 对每个一级部分至少说明：
   - 本节要写什么（写作任务）
   - 关键证据或数据来源是什么
   - 哪些地方需要审慎表述或标注边界
   - 如涉及多源信息，标注来源差异（矛盾/互补/侧重不同）
5. **建议补充材料** — 指出整合分析还需要补哪些公开证据、数据或对照材料

## 期望出现的关键特征

- 一级标题围绕核心分析主题展开，绝不按材料来源分章节（不出现"一、材料 A 分析 / 二、材料 B 分析"式结构）
- 提纲反映了对 2–3 份材料的实质性整合：同一主题下融合不同来源信息，而非简单并列
- 来源间差异或矛盾被显式标注（如"两份材料对 XX 影响程度判断不一致""材料 A 侧重 XX，材料 B 侧重 YY"）
- 当来源信息互补时，整合结果体现综合判断而非偏向某一来源
- 二级展开建议中，每个一级部分下至少包含 3 项具体写作指引（写什么 / 关键证据 / 审慎之处 / 来源差异四个维度中至少覆盖两项）
- 建议补充材料列出至少 2 项整合分析所需的额外信息
- 如来源间对同一事项存在矛盾判断，输出未直接选边站，而是保留差异并标注需要进一步核实

## 不应出现的问题

- 按材料来源分章节（如"一、材料 A 分析 二、材料 B 分析"），而非按主题整合
- 忽略材料间的矛盾或差异，输出仿佛所有材料说法完全一致
- 将某一份材料的观点直接作为总体结论，不提及其他材料的差异视角
- 编造材料中未提及的信息以"补齐"分析或"调和"矛盾
- 二级展开只列标题不说明写作方向
- 输出与输入材料弱相关的万能分析框架
- 一级标题之间内容重叠或逻辑顺序混乱
- 建议补充材料空泛（如"补充更多研究"），无具体指向

### 高风险错误触发条件（本 case 特化）

| 高风险错误类型 | 本 case 触发条件 |
|----------------|------------------|
| 编造事实 | 输出中出现所有输入材料均未包含的具体数字、机构名、政策名称 |
| 编造政策口径 | 模拟了所有输入材料中均不存在的监管要求或内部标准 |
| 越界推断 | 将某一份材料的不确定判断直接写成综合确定结论；或在来源矛盾时选择性地只呈现一面 |
| 风格严重偏离 | 输出呈新闻综述、券商研报营销风格，而非正式研究报告提纲 |
| 空泛建议 | 建议措施仅含"加强重视""持续关注"等，无具体行动方向 |
| 漏标不确定性 | 来源间存在明显矛盾或差异，但输出未做任何标注 |

## 验收口径

| 条件 | 判定 | 检查方式 |
|------|------|----------|
| 五段结构完整存在 | 必须通过 | 逐段确认存在 |
| 一级提纲按主题整合（非按来源分章） | 必须通过 | 检查一级标题是否与来源一一对应 |
| 一级提纲数量 4–6 个，各有作用说明 | 必须通过 | 计数 + 逐条检查是否有说明句 |
| 二级展开至少覆盖"写什么"和"来源差异/审慎"两个维度 | 必须通过 | 逐节抽样检查 |
| 来源差异被显式标注（矛盾/互补/侧重不同至少覆盖一种） | 必须通过 | 搜索差异标注语句 |
| 无编造事实/数据/政策 | 必须通过 | 抽查所有具体数字、指标、机构名是否材料中有出处 |
| 建议补充材料 ≥2 项且具体 | 必须通过 | 计数 + 检查是否有具体指向 |
| 核心结论/写作主线 ≤3 句 | 建议通过 | 计数 |
| 整合分析未偏向单一来源 | 建议通过 | 抽查是否有来源被完全忽略 |
