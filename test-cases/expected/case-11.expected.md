# Case 11 Expected: ppt-outline-exec

## 期望输出结构

输出必须包含以下四个核心模块；第 5 项仅在用户明确有汇报需求时提供：

1. **建议总标题** — 概括汇报主题与结论方向
2. **汇报主线（1–2 句）** — 极简概括 PPT 核心逻辑
3. **页级提纲（3–5 页）** — 每页必须包含以下全部字段：
   - 页标题（观点化，非目录式）
   - 本页核心信息（1 句话）
   - 不超过 4 个支撑点（每点为一行短句）
   - 本页作用（标注为：背景 / 判断 / 对比 / 影响 / 风险 / 建议 / 总结 之一）
   - 备注栏建议（如有适合口头补充但不宜上屏的内容）
4. **不建议上 PPT 的内容** — 单独列出，至少 3 项
5. **可选：1 分钟口头摘要** — 仅在用户明确要求汇报版口头提要时检查是否提供

## 期望出现的关键特征

### 结论先行检查（本 case 核心判据）
- **第 1 页必须为总体判断或核心结论**，不得为背景介绍、政策概述或情况说明
- 第 1 页的页标题必须包含实质性判断，不能是"背景""概述"等开场类标题
- 第 1 页的作用标注必须为"判断"或"总结"类，而非"背景"
- 如存在建议或关注点，应单独成页或并入最后一页，不得散落各页

### 结构性检查
- 页级提纲中每一页都包含完整的五个字段（页标题、核心信息、支撑点、作用、备注建议）
- 总页数在 3–5 页范围内
- 每页支撑点控制在 3–4 个（管理层汇报版密度更高但更精炼）
- 汇报主线为 1–2 句话

### 观点化标题检查
- 观点化标题占全部页标题的比例 ≥ 60%（即 3 页中至少 2 页、5 页中至少 3 页）
- 不得有任何页标题匹配以下禁止模式：背景介绍、相关情况、政策解读、风险分析、下一步工作、建议措施、现状概述、基本概况
- 标题应直接承载判断或结论信息，而非仅标示话题范围

### 管理层汇报适配检查
- 页标题和支撑点适合汇报场景：简洁、可直接讲述、无需额外解释
- 建议或关注点具体可执行，而非空泛建议（如"加强重视""持续推进""统筹做好相关工作"视为不合格）
- 整体风格稳健审慎，标题和支撑点中不下过满结论

### 不建议上 PPT 列表检查
- 至少列出 3 项不建议上屏的内容
- 列表内容须具体指向某类信息，不得为空泛概括

### 边界标注检查
- 若输入材料中存在不确定性，须明确标注
- 不得对材料无法支持的内容做出强结论
- 若材料不足或信息有限，不得让输出表现得像材料充分

## 不应出现的问题

### 高风险错误触发条件（出现任一项 → 不通过）
- **编造事实**：输出中出现输入材料不包含的具体数字、日期、机构名、政策名称
- **编造政策口径**：模拟了输入材料中不存在的监管要求、内部标准或实施口径
- **越界推断**：将材料中的不确定信息写成确定结论
- **风格严重偏离**：输出呈明显新闻稿、营销稿或口语化风格
- **空泛建议**：建议部分只含"加强重视""持续推进""统筹做好相关工作"等无实质内容的表述
- **漏标不确定性**：材料不足或存在不确定信息时未做任何标注，输出表现得像材料充分

### 结论先行违反（出现任一项 → 不通过）
- 第 1 页为"背景介绍""现状概述"或类似开场内容，未做到结论先行
- 第 1 页页标题不含任何判断性信息

### Hard Rules 违反（出现任一项 → 不通过）
- 页标题使用目录式空标题
- 单页支撑点 ≥ 5 个（管理层汇报版上限更严格）
- 把长段原文直接搬入页面
- 在标题中给出材料无法支持的强结论

### 建议项（出现 → 建议修改但不自动判不通过）
- 汇报主线超过 2 句
- 建议部分虽有内容但可操作性不足
- 用户已明确需要口头提要，但未提供"1 分钟口头摘要"

## 验收口径

| 条件 | 判定 | 检查方式 |
|------|------|----------|
| 四个核心输出模块齐全 | 必须通过 | 逐模块核对建议总标题/汇报主线/页级提纲/不建议上 PPT 的内容是否存在 |
| 每页包含全部五个页级字段 | 必须通过 | 逐页核对 |
| 第 1 页为结论/判断 | 必须通过 | 检查第 1 页标题是否含判断、作用是否为"判断"或"总结"类 |
| 总页数 3–5 页 | 必须通过 | 计数 |
| 每页支撑点 ≤ 4 个 | 必须通过 | 逐页计数 |
| 观点化标题占比 ≥ 60% | 必须通过 | 统计 |
| 无页标题落入禁止模式列表 | 必须通过 | 逐标题比对 |
| 无编造事实或政策口径 | 必须通过 | 抽查支撑点是否可回溯到输入材料 |
| 无越界推断 | 必须通过 | 检查标题与支撑点中的确定性措辞 |
| 无空泛建议 | 必须通过 | 检查建议内容是否可执行 |
| 不确定信息已标注 | 必须通过 | 检查是否存在边界标注 |
| "不建议上 PPT"列表 ≥ 3 项 | 必须通过 | 计数 |
| 汇报主线 1–2 句 | 建议通过 | 计数 |
| 用户明确需要口头提要时提供 1 分钟口头摘要 | 建议通过 | 仅在用户需求明确时检查 |
