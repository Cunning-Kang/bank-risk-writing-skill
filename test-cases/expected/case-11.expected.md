# Case 11 Expected: ppt-outline-exec

## 期望输出结构

1. 建议总标题
2. 汇报主线（1–2 句）
3. 页级提纲（3–5 页）
   - 每页：观点化标题 + 不超过 4 个支撑点 + 本页作用
4. 不建议上 PPT 的内容
5. 可选：1 分钟口头摘要

## 期望出现的关键特征

- 第一页即为总体判断或核心结论
- 页数控制在 3–5 页
- 页标题观点化且适合汇报场景
- 每页支撑点精炼（≤4 个）
- 整体风格稳健，不下过满结论

## 不应出现的问题

- 第一页为"背景介绍"，未做到结论先行
- 页数超过 6 页
- 每页支撑点过多
- 在标题中下过满结论
- 缺少对不确定性的标注

## 验收口径

| 条件 | 判定 |
|------|------|
| 首页为结论 | 必须通过 |
| 页数 ≤5 | 必须通过 |
| 每页支撑点 ≤4 | 必须通过 |
| 无过满结论 | 必须通过 |
| 无编造信息 | 必须通过 |
