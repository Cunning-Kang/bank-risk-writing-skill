# Case 12 Expected: ppt-outline-restructure

## 期望输出结构

1. 建议总标题
2. 汇报主线
3. 页级提纲（6–10 页）
   - 每页：观点化标题 + 3–5 个支撑点 + 本页作用
4. 不建议上 PPT 的内容（应内容丰富，说明做了取舍）
5. 可选：1 分钟口头摘要

## 期望出现的关键特征

- 选取的内容是最有汇报价值的部分，而非面面俱到
- "不建议上 PPT"列表内容丰富，说明做了认真取舍
- 每页信息密度适中（3–5 个支撑点）
- 页标题观点化
- 整体逻辑从结论到支撑到建议
- 总页数控制在 6–10 页

## 不应出现的问题

- 试图把长文所有内容都搬上 PPT
- 每页支撑点超过 7 个
- 页标题为目录式
- "不建议上 PPT"部分为空或过于简略
- 编造原文中未包含的信息
- 取舍标准不清晰

## 验收口径

| 条件 | 判定 |
|------|------|
| 做了明确取舍 | 必须通过 |
| 页标题观点化 | 必须通过 |
| 每页支撑点 ≤5 | 必须通过 |
| "不建议上 PPT"列表内容充实 | 必须通过 |
| 无编造信息 | 必须通过 |
