# Case 12 Expected: ppt-outline-restructure

## 期望输出结构

输出必须包含以下四个核心模块；第 5 项仅在用户明确有汇报需求时提供：

1. **建议总标题** — 概括汇报主题与结论方向
2. **汇报主线（2–4 句）** — 说明 PPT 讲述逻辑，体现取舍思路
3. **页级提纲（6–10 页）** — 每页必须包含以下全部字段：
   - 页标题（观点化，非目录式）
   - 本页核心信息（1 句话）
   - 3–5 个支撑点（每点为一行短句）
   - 本页作用（标注为：背景 / 判断 / 对比 / 影响 / 风险 / 建议 / 总结 之一）
   - 备注栏建议（如有适合口头补充但不宜上屏的内容）
4. **不建议上 PPT 的内容** — 单独列出，至少 5 项（体现对长文的取舍判断）
5. **可选：1 分钟口头摘要** — 仅在用户明确要求汇报版口头提要时检查是否提供

## 期望出现的关键特征

### 取舍判据检查（本 case 核心判据）
- "不建议上 PPT 的内容"列表 ≥ 5 项，且每项须具体说明为何不适合上屏（如"需连续解释的背景细节""过长数字明细""证据来源与方法说明"等）
- 页级提纲中选取的内容应为最有汇报价值的部分，而非试图覆盖原文全部章节
- 不建议上屏的内容应可回溯到输入材料中的具体段落或信息类别，不得为空泛的"部分细节"
- 输出总体体量应明显小于输入材料（输入 5000–10000 字 → 输出 6–10 页提炼），证明做了实质取舍

### 结构性检查
- 页级提纲中每一页都包含完整的五个字段（页标题、核心信息、支撑点、作用、备注建议）
- 总页数在 6–10 页范围内
- 每页支撑点控制在 3–5 个
- 汇报主线为 2–4 句话，须体现取舍逻辑（如"本提纲聚焦……，其余……详见备注/附件"）

### 观点化标题检查
- 观点化标题占全部页标题的比例 ≥ 60%（即 6 页中至少 4 页、10 页中至少 6 页）
- 不得有任何页标题匹配以下禁止模式：背景介绍、相关情况、政策解读、风险分析、下一步工作、建议措施、现状概述、基本概况
- 观点化标题应承载实质性判断或信息指向

### 页逻辑检查
- 页间遵循合理的汇报逻辑顺序
- 相邻页面之间无重复内容
- 同类信息未拆散到多页造成冗余

### 信息密度检查
- 每页支撑点均为一行短句，不得出现跨行长段落
- 所有页面的表达密度基本一致

### 边界标注检查
- 若输入材料中存在不确定性或信息不足之处，输出中须明确标注
- 不得对材料无法支持的内容做出强结论
- 对被取舍掉的内容中的不确定性信息，也应在备注或不建议列表中提示

## 不应出现的问题

### 高风险错误触发条件（出现任一项 → 不通过）
- **编造事实**：输出中出现输入材料不包含的具体数字、日期、机构名、政策名称
- **编造政策口径**：模拟了输入材料中不存在的监管要求、内部标准或实施口径
- **越界推断**：将材料中的不确定信息写成确定结论
- **风格严重偏离**：输出呈明显新闻稿、营销稿或口语化风格
- **空泛建议**：建议或关注点只含"加强重视""持续推进"等无实质动作方向的表述
- **漏标不确定性**：材料不足时未做任何标注，输出表现得像材料充分

### 取舍失败触发条件（出现任一项 → 不通过）
- "不建议上 PPT"列表少于 5 项
- 页级提纲试图逐章逐节搬运原文结构（如原文有 8 个章节，PPT 也机械映射为 8 页）
- 单页支撑点 ≥ 6 个（文字墙判定）

### Hard Rules 违反（出现任一项 → 不通过）
- 页标题使用目录式空标题
- 把长段原文直接搬入页面
- 在标题中给出材料无法支持的强结论
- 为追求"完整覆盖"原文而牺牲可讲述性

### 建议项（出现 → 建议修改但不自动判不通过）
- 汇报主线未体现取舍思路
- 个别页标题观点化程度不足（但未落入禁止模式列表）
- 用户已明确需要口头提要，但未提供"1 分钟口头摘要"

## 验收口径

| 条件 | 判定 | 检查方式 |
|------|------|----------|
| 四个核心输出模块齐全 | 必须通过 | 逐模块核对建议总标题/汇报主线/页级提纲/不建议上 PPT 的内容是否存在 |
| 每页包含全部五个页级字段 | 必须通过 | 逐页核对 |
| 总页数 6–10 页 | 必须通过 | 计数 |
| 每页支撑点 3–5 个 | 必须通过 | 逐页计数 |
| 观点化标题占比 ≥ 60% | 必须通过 | 统计 |
| 无页标题落入禁止模式列表 | 必须通过 | 逐标题比对 |
| 无编造事实或政策口径 | 必须通过 | 抽查支撑点是否可回溯到输入材料 |
| 无越界推断 | 必须通过 | 检查确定性措辞是否有材料支撑 |
| "不建议上 PPT"列表 ≥ 5 项 | 必须通过 | 计数 |
| 不建议列表每项有具体理由 | 必须通过 | 逐项检查是否说明为何不上屏 |
| 未逐章搬运原文结构 | 必须通过 | 对比输出页结构与输入章节结构，检查是否机械映射 |
| 不确定信息已标注 | 必须通过 | 检查是否存在边界标注 |
| 汇报主线体现取舍思路 | 建议通过 | 检查主线是否提到聚焦/取舍/省略 |
| 输出体量明显小于输入 | 建议通过 | 定性比较 |
| 用户明确需要口头提要时提供 1 分钟口头摘要 | 建议通过 | 仅在用户需求明确时检查 |
