# Case 02 Expected: policy-brief-exec

## 期望输出结构

1. 核心结论（1–3 句总体判断）
2. 关键点（3–5 条）
3. 建议关注事项 / 待核实事项

## 期望出现的关键特征

- 首段即为总体判断或核心结论，非背景介绍
- 关键点数量控制在 3–5 条
- 每条关键点信息密度高
- 建议关注事项具体可操作
- 篇幅控制在 800–1500 字
- 无大段政策原文复述

## 不应出现的问题

- 开头使用"本文介绍了……"等目录式描述
- 关键点超过 7 条
- 建议部分出现空泛建议（如"加强重视""持续推进"）
- 篇幅超过 2000 字
- 将不确定影响写成确定结论

## 验收口径

| 条件 | 判定 |
|------|------|
| 首段为结论而非背景 | 必须通过 |
| 关键点 ≤5 条 | 必须通过 |
| 无空泛建议 | 必须通过 |
| 篇幅 ≤2000 字 | 必须通过 |
| 无编造事实 | 必须通过 |
