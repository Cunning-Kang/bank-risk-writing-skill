# Case 02 Expected: policy-brief-exec

## 期望输出结构

汇报版输出应严格包含以下三个段落，顺序与 policy-brief 汇报版结构一致：

1. **核心结论** — 首段 1–3 句总体判断，直接回答"这个政策/文件的核心内容是什么、对我们意味着什么"
2. **关键点** — 3–5 条，每条信息密度高，聚焦最重要内容
3. **建议关注事项 / 待核实事项** — 具体可操作的后续关注方向

### 结构性检查项

| 检查项 | 合格条件 |
|--------|----------|
| 三段结构完整 | 缺任一段落 → 不通过 |
| 首段为结论 | 第一段文字必须是对核心内容的判断，不得以背景介绍或文件描述开头 |
| 关键点数量 | 3–5 条（≤5 条） |
| 篇幅 | ≤1500 字 |
| 无政策原文大段复述 | 单段引用原文不得超过 80 字 |

## 期望出现的关键特征

- 首段第一句话即为总体判断或核心结论，而非"本文介绍了……""XX 文件于 XX 日发布……"等背景性描述
- 关键点每条聚焦单一要点，信息密度高，无冗余铺垫
- 待核实/建议关注事项每条包含可操作的后续行动方向（如"需核对 XX 细则的具体适用范围""建议跟进 XX 数据观察"），而非"加强重视""持续推进"等空泛表述
- 整体风格正式、克制、非媒体化
- 篇幅控制在 800–1500 字之间

## 不应出现的问题

### 高风险错误触发条件（出现任一项即判不通过）

| 高风险错误 | 本 case 具体触发条件 |
|------------|---------------------|
| 编造事实 | 输出中出现输入材料不包含的具体数字、日期、机构名、政策名称 |
| 编造政策口径 | 模拟了不存在的监管要求或内部标准 |
| 越界推断 | 将不确定影响写成确定结论 |
| 风格严重偏离 | 首段以背景介绍开头而非结论；或整体呈媒体/宣传风格 |
| 空泛建议 | 建议部分只含"加强重视""持续推进""统筹做好相关工作"等无具体行动方向的表述 |
| 漏标不确定性 | 对材料不充分的部分未做任何待核实标注 |

### 其他禁止项

- 首段使用"本文介绍了……""XX 机构于 XX 日印发了……"等目录式/描述式开头
- 关键点超过 5 条
- 篇幅超过 1500 字
- 大段复述政策原文（单段引用 >80 字）
- 将"建议""鼓励"类表述升级为"必须""要求"
- 在无对比依据时使用"新变化""明显收紧"等表述

## 验收口径

| 条件 | 判定 | 说明 |
|------|------|------|
| 首段为结论而非背景 | 必须通过 | 首段第一句必须是对核心内容的判断 |
| 关键点 ≤5 条 | 必须通过 | 超过 5 条 → 不通过 |
| 无空泛建议 | 必须通过 | 每条建议需包含具体行动方向 |
| 篇幅 ≤1500 字 | 必须通过 | 超过 → 不通过 |
| 无编造事实 | 必须通过 | 对照输入材料检查 |
| 无越界推断 | 必须通过 | 不确定影响不得写成确定结论 |
| 待核实事项存在 | 必须通过 | 至少 1 条待核实/建议关注事项 |
| 风格正式审慎 | 必须通过 | 无媒体腔、宣传腔 |
| 无大段复述 | 建议通过 | 单段引用 ≤80 字 |
