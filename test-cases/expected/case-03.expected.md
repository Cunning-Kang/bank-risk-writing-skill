# Case 03 Expected: policy-brief-boundary

## 期望输出结构

输出应包含以下五个段落（与 policy-brief 默认结构一致，但每段均需体现材料不足的边界标注）：

1. **文件概况** — 在常规字段（主题、性质、发文机构）基础上，必须包含材料充足性声明，如"基于不完整材料整理""部分文件信息待补充"
2. **核心要点** — 仅覆盖输入材料中确实存在的内容；对材料未覆盖的方面，以边界标注替代猜测
3. **关键变化或重点关注** — 如材料不足以支撑前后对比，不得使用"变化"表述，改写为"值得关注的重点"或跳过本节并说明原因
4. **可能影响** — 每条影响必须附有审慎限定词；对材料不足以支撑的影响判断，明确标注"当前材料尚不足以支持相关判断"
5. **后续关注点 / 待核实事项** — 必须包含：哪些方面因材料不足无法判断、需要补充哪些具体材料、哪些内容需等待后续正式文件发布后核实

### 结构性检查项

| 检查项 | 合格条件 |
|--------|----------|
| 五段结构完整 | 缺任一段落 → 不通过 |
| 文件概况含材料充足性声明 | 必须出现"基于不完整材料"或等效标注 |
| 核心要点仅覆盖已知部分 | 不可出现无材料支撑的要点 |
| 变化表述有依据 | 无对比依据时不得使用"变化""新增"等表述 |
| 待核实事项覆盖材料缺口 | 必须列出需要补充的具体材料类型或来源 |

## 期望出现的关键特征

### 必须出现的边界标注模式（至少出现以下 3 类）

| 标注类型 | 示例措辞（不要求逐字匹配，但语义和功能需对应） |
|----------|------------------------------------------------|
| 材料充足性声明 | "基于现有材料整理""部分信息待补充""材料覆盖范围有限" |
| 事实与推断的分隔标记 | "已披露事实为…""基于当前材料的初步判断为…""上述为分析推断，非文件明示内容" |
| 审慎限定词 | "从当前公开材料看""基于现有资料可初步判断""相关影响仍需结合后续规则进一步观察" |
| 缺失信息指向 | "需补充原文中关于 XX 的具体条款""需等待 XX 配套细则发布""正式使用前建议核对 XX 原文" |
| 不确定性标记 | "当前材料尚不足以支持更强结论""该项影响有待结合后续数据进一步确认""需结合正式文件进一步确认" |

### 额外特征

- 核心要点中，每一条均可直接对应到输入材料中的具体文字，无脱离材料的概括
- 后续补充建议指向具体信息缺口（如"需补充文件生效日期""需确认适用机构范围"），而非笼统的"需补充更多信息"
- 整体输出读起来不像是材料充分时的正常简报——即评审者无需与输入材料逐字比对，仅从输出自身的标注密度即可感知材料不足

## 不应出现的问题

### 高风险错误触发条件（出现任一项即判不通过）

| 高风险错误 | 本 case 具体触发条件 |
|------------|---------------------|
| 编造事实 | 输出中出现输入材料不包含的具体数字、日期、机构名、政策名称 |
| 编造政策口径 | 模拟了不存在的监管要求、实施细则或配套安排 |
| 越界推断 | 对材料未覆盖的方面做出确定性判断，或把推测写成确认结论 |
| 漏标不确定性 | 输出中无任何材料不足标注、审慎限定或待核实事项，呈现效果与材料充分时无差别 |
| 空泛建议 | 后续补充建议仅写"需补充材料"而不指明具体缺什么 |
| 风格严重偏离 | 输出呈媒体/宣传风格 |

### 其他禁止项

- 对模糊信息做过度解读（如将"研究推进"解读为"即将实施"）
- 未区分"已知信息"和"推断信息"
- 在无对比依据时使用"新变化""明显收紧""重大调整"等表述
- 把推测性分析伪装成文件明示内容
- 遗漏明显的待核实事项（如文件中明确提到"另行规定"却未标注）

## 验收口径

| 条件 | 判定 | 说明 |
|------|------|------|
| 五段结构完整 | 必须通过 | 缺任一段落 → 不通过 |
| 文件概况含材料充足性声明 | 必须通过 | 未标注材料不足 → 不通过 |
| 边界标注 ≥3 类 | 必须通过 | 少于 3 类 → 不通过 |
| 无编造信息 | 必须通过 | 对照输入材料检查 |
| 审慎措辞到位 | 必须通过 | 可能影响部分每条均有限定词 |
| 待核实事项具体 | 必须通过 | 每条指向具体信息缺口，非笼统"需补充" |
| 事实与推断可区分 | 必须通过 | 评审者能分辨哪些是材料明示、哪些是分析推断 |
| 输出自身可感知材料不足 | 建议通过 | 仅从输出文本即可感知材料不充分，无需对照输入 |
