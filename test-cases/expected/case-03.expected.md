# Case 03 Expected: policy-brief-boundary

## 期望输出结构

1. 文件概况（标注"基于不完整材料"）
2. 核心要点（仅覆盖已知部分）
3. 材料不足说明（明确标注缺失信息）
4. 后续补充建议

## 期望出现的关键特征

- 输出中明确出现"材料不足""待补充""基于现有材料"等标注
- 对缺失信息的处理方式是标注而非猜测
- 核心要点仅覆盖输入材料中确实存在的内容
- 使用审慎措辞（如"从当前材料看""有待结合后续规则进一步判断"）
- 后续补充建议具体，指明需要补充哪些信息

## 不应出现的问题

- 编造输入材料中未提及的政策条款或数字
- 输出看起来像材料充分（无任何不足标注）
- 对模糊信息做了过度解读
- 未区分"已知信息"和"推断信息"

## 验收口径

| 条件 | 判定 |
|------|------|
| 明确标注材料不足 | 必须通过 |
| 无编造信息 | 必须通过 |
| 审慎措辞到位 | 必须通过 |
| 后续补充建议具体 | 建议通过 |
