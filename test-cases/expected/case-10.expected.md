# Case 10 Expected: ppt-outline-basic

## 期望输出结构

1. 建议总标题
2. 汇报主线（1–2 句）
3. 页级提纲（5–8 页）
   - 每页：观点化标题 + 3–5 个支撑点 + 本页作用
4. 不建议上 PPT 的内容
5. 可选：1 分钟口头摘要

## 期望出现的关键特征

- 页标题为观点化表述（如"政策变化对……提出了更明确要求"）
- 每页 3–5 个支撑点
- 页间逻辑清晰连贯
- 有明确的"不建议上 PPT"列表
- 总页数控制在 5–8 页范围内

## 不应出现的问题

- 页标题为目录式命名（如"背景介绍""风险分析"）
- 一页超过 7 个支撑点
- 把长段文字直接搬入 PPT 页面
- 在标题中使用过满结论
- 编造输入材料中未包含的信息

## 验收口径

| 条件 | 判定 |
|------|------|
| 页标题观点化 | 必须通过 |
| 每页支撑点 ≤5 | 必须通过 |
| 页间逻辑连贯 | 必须通过 |
| 无编造信息 | 必须通过 |
| 总页数在 5–8 范围内 | 建议通过 |
