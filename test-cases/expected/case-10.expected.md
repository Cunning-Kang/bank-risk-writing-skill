# Case 10 Expected: ppt-outline-basic

## 期望输出结构

输出必须包含以下四个核心模块；第 5 项仅在用户明确有汇报需求时提供：

1. **建议总标题** — 能概括整份汇报的主题与结论方向
2. **汇报主线** — 2–4 句话说明 PPT 的讲述逻辑
3. **页级提纲（5–8 页）** — 每页必须包含以下全部字段：
   - 页标题（观点化，非目录式）
   - 本页核心信息（1 句话概括本页要传达的核心判断或信息）
   - 3–5 个支撑点（每点为一行短句，不得出现长段落）
   - 本页作用（标注为：背景 / 判断 / 对比 / 影响 / 风险 / 建议 / 总结 之一）
   - 备注栏建议（如有适合口头补充但不宜上屏的内容）
4. **不建议上 PPT 的内容** — 单独列出，至少 3 项
5. **可选：1 分钟口头摘要** — 仅在用户明确要求汇报版口头提要时检查是否提供

## 期望出现的关键特征

### 结构性检查
- 页级提纲中每一页都包含完整的五个字段（页标题、核心信息、支撑点、作用、备注建议）
- 总页数在 5–8 页范围内
- 每页支撑点控制在 3–5 个
- 汇报主线为 2–4 句话，能概括整体逻辑走向

### 观点化标题检查
- 观点化标题占全部页标题的比例 ≥ 60%（即 5 页中至少 3 页、8 页中至少 5 页）
- 不得有任何页标题匹配以下禁止模式：背景介绍、相关情况、政策解读、风险分析、下一步工作、建议措施、现状概述、基本概况
- 观点化标题应包含实质性判断或信息指向（如"……呈现出若干特征""……提出了更明确要求"），而非空泛标签

### 页逻辑检查
- 页间遵循以下逻辑顺序（允许合理调整）：总体判断 → 背景与变化 → 核心观察 → 主要影响或风险 → 建议动作 → 总结（可选）
- 相邻页面之间无重复内容
- 同类信息未拆散到多页

### 信息密度检查
- 每页支撑点均为一行短句，不得出现跨行长段落
- 所有页面的表达密度基本一致，无某页明显过载或明显过空

### 不建议上 PPT 列表检查
- 至少列出 3 项不建议上屏的内容
- 列表内容须具体指向输入材料中的某类信息（如"过长的政策条文原文""过多数字明细""需连续解释的背景细节"等），不得为空泛概括

### 边界标注检查
- 若输入材料中存在不确定性或信息不足之处，输出中须明确标注（使用"基于现有材料""需进一步核实"等措辞）
- 不得对材料无法支持的内容做出强结论

## 不应出现的问题

### 高风险错误触发条件（出现任一项 → 不通过）
- **编造事实**：输出中出现输入材料不包含的具体数字、日期、机构名、政策名称
- **编造政策口径**：模拟了输入材料中不存在的监管要求、内部标准或实施口径
- **越界推断**：将材料中的不确定信息写成确定结论（如把"可能影响"写成"将导致"）
- **风格严重偏离**：输出呈明显新闻稿、营销稿或口语化风格
- **空泛建议**：建议或关注点只含"加强重视""持续推进"等无实质动作方向的表述
- **漏标不确定性**：材料存在信息不足或不确定性，但输出未做任何边界标注

### Hard Rules 违反（出现任一项 → 不通过）
- 页标题使用目录式空标题（参见上方禁止模式列表）
- 单页出现 6 个及以上支撑点（即"文字墙"判定）
- 把长段原文直接搬入页面支撑点
- 在标题中给出材料无法支持的强结论（如"将大幅下降""必然导致"）

### 建议项（出现 → 建议修改但不自动判不通过）
- 汇报主线超过 4 句或不足 2 句
- 个别页标题观点化程度不足（但未落入禁止模式列表）
- 用户已明确需要口头提要，但未提供"1 分钟口头摘要"

## 验收口径

| 条件 | 判定 | 检查方式 |
|------|------|----------|
| 四个核心输出模块齐全 | 必须通过 | 逐模块核对建议总标题/汇报主线/页级提纲/不建议上 PPT 的内容是否存在 |
| 每页包含全部五个页级字段 | 必须通过 | 逐页核对：页标题/核心信息/支撑点/作用/备注建议 |
| 观点化标题占比 ≥ 60% | 必须通过 | 统计观点化标题数 ÷ 总页数 |
| 无页标题落入禁止模式列表 | 必须通过 | 逐标题比对禁止列表 |
| 每页支撑点 3–5 个 | 必须通过 | 逐页计数 |
| 总页数 5–8 页 | 必须通过 | 计数 |
| 无编造事实或政策口径 | 必须通过 | 抽查支撑点是否可回溯到输入材料 |
| 无越界推断 | 必须通过 | 检查标题与支撑点中是否有材料不支持的强判断 |
| "不建议上 PPT"列表 ≥ 3 项 | 必须通过 | 计数 |
| 汇报主线 2–4 句 | 建议通过 | 计数 |
| 不确定信息已标注 | 建议通过 | 检查是否存在"待核实""基于现有材料"等标注 |
| 用户明确需要口头提要时提供 1 分钟口头摘要 | 建议通过 | 仅在用户需求明确时检查 |
