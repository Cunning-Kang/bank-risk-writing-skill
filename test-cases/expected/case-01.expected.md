# Case 01 Expected: policy-brief-basic

## 期望输出结构

1. 文件概况（主题、性质、发文机构）
2. 核心要点（分条列出）
3. 可能影响（基于材料的分析）
4. 后续关注点 / 待核实事项

## 期望出现的关键特征

- 文件概况准确反映输入材料的主题和性质
- 核心要点每条对应原文具体内容，数量 3–8 条
- 可能影响部分使用审慎措辞（如"从当前材料看""初步可见"）
- 后续关注点列出 2–5 项需要进一步确认的内容
- 整体风格正式、中性、无媒体腔

## 不应出现的问题

- 编造原文未提及的政策条款、数字或日期
- 将"建议""鼓励"类表述升级为"必须""要求"
- 使用新闻稿、宣传稿或评论稿风格
- 对材料未覆盖的范围做出确定性判断

## 验收口径

| 条件 | 判定 |
|------|------|
| 结构完整（四个部分均存在） | 必须通过 |
| 核心要点与原文可对应 | 必须通过 |
| 无编造事实 | 必须通过 |
| 风格正式审慎 | 必须通过 |
| 后续关注点不少于 2 条 | 建议通过 |
