# Case 01 Expected: policy-brief-basic

## 期望输出结构

输出应严格包含以下五个段落，顺序与 policy-brief 默认结构一致：

1. **文件概况** — 文件主题、文件性质、发文机构；发布日期或生效信息仅在材料明确提供时写入，未提供时标注"材料未提供"
2. **核心要点** — 分条列出；每条对应原文具体条款或明示要求；数量 3–8 条
3. **关键变化或重点关注** — 仅在存在对比依据时使用"变化""新增要求""明显收紧"等表述；如无对比依据，改写为"值得关注的重点"；不得凭推断编造变化
4. **可能影响** — 基于材料的分析；必须区分对风险管理 / 合规 / 业务管理 / 后续研究等维度的可能影响，且每条影响使用审慎措辞
5. **后续关注点 / 待核实事项** — 列出仍需核对原文口径的表述、仍需结合后续细则观察的部分、正式使用前建议进一步确认的内容；数量 ≥2 条

## 期望出现的关键特征

- 文件概况准确反映输入材料的主题和性质，未提供的信息做了"材料未提供"类标注而非留空
- 核心要点每条均可回溯至原文具体内容，无脱离原文的概括
- "变化"类表述仅在存在明确对比依据时出现；如材料不涉及前后对比，本节标题或内容改为"值得关注的重点"而非"关键变化"
- 可能影响部分至少出现 1 次审慎措辞标记（如"从当前材料看""基于现有资料可初步判断""相关影响仍需结合后续规则进一步观察"等）
- 待核实事项覆盖：实施范围不明确、时间安排不明确、责任主体不明确、执行细节不明确中至少 2 类
- 整体风格正式、中性、克制；无媒体腔、宣传腔、评论腔

### 结构性检查项

| 检查项 | 合格条件 |
|--------|----------|
| 五个段落均存在 | 缺任一段落 → 不通过 |
| 核心要点数量 | 3–8 条 |
| 待核实事项数量 | ≥2 条 |
| 变化/新增表述 | 仅在有对比依据时出现；无依据时改写为"重点关注" |
| 审慎措辞标记 | 可能影响部分 ≥1 处 |

## 不应出现的问题

### 高风险错误触发条件（出现任一项即判不通过）

| 高风险错误 | 本 case 具体触发条件 |
|------------|---------------------|
| 编造事实 | 输出中出现输入材料不包含的具体数字、日期、机构名、政策名称 |
| 编造政策口径 | 模拟了不存在的监管要求、内部标准或配套安排 |
| 越界推断 | 将"建议""鼓励"类表述升级为"必须""要求"；或将不确定影响写成确定结论 |
| 风格严重偏离 | 输出呈明显新闻稿、营销稿或口语化风格 |
| 空泛建议 | 建议部分只含"加强重视""持续推进""统筹做好"等无实质行动方向的表述 |
| 漏标不确定性 | 待核实事项缺失，或输出表现得像材料充分 |

### 其他禁止项

- 在无对比依据时使用"新变化""明显收紧""重大调整"等确定性变化表述
- 将基于材料的分析判断混同于文件明示要求
- 使用新闻稿、宣传稿或评论稿风格
- 推演用户未要求的内部执行方案
- 补造数据、机构态度、实施时点或监管目的

## 验收口径

| 条件 | 判定 | 说明 |
|------|------|------|
| 五段结构完整 | 必须通过 | 缺任一段落 → 不通过 |
| 核心要点与原文可对应 | 必须通过 | 每条可在原文中找到出处 |
| 无编造事实 | 必须通过 | 对照输入材料检查数字、日期、机构名、政策名 |
| 无越界推断 | 必须通过 | "建议/鼓励"不得写成"必须/要求"；不确定影响不得写成确定结论 |
| 变化表述有依据 | 必须通过 | 出现"变化""新增"等表述时必须有对比依据 |
| 待核实事项 ≥2 条 | 必须通过 | 且需覆盖至少 2 类不明确信息 |
| 风格正式审慎 | 必须通过 | 无媒体腔、宣传腔、评论腔 |
| 无空泛建议 | 建议通过 | 每条建议应包含可操作的后续行动方向 |
