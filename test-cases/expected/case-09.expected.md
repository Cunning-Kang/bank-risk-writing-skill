# Case 09 Expected: report-outline-insufficient-input

## 期望输出结构

输出必须遵循 `report-outline` skill 的默认五段结构，并在开头或标题前带有明确的"初步框架"标注：

1. **推荐标题** — 明确主题，可带有"初步""基于有限材料"等限定词
2. **核心结论 / 写作主线** — 1–3 句，明确标注为初步判断，不得使用确定性断言
3. **初步一级提纲** — 一级标题数量 ≤3 个（与 200–500 字材料信息量匹配），各章附作用说明
4. **二级展开建议** — 对每个一级部分至少说明"写什么"以及"该部分需要什么额外证据才能写实"；允许简化，但不得缺失为独立模块
5. **建议补充材料** — 具体指明缺少什么类型的材料（至少列出 3 项具体缺失类别及用途说明）

注：除上述五段外，输出开头还须直接说明"以下为基于现有材料形成的初步框架"或等义表述。

## 期望出现的关键特征

- 输出开头显式出现"当前材料仅能支撑初步框架""以下为基于有限材料的初步提纲"等边界标注语句
- 一级标题数量 ≤3 个，与材料实际信息量匹配（材料仅 200–500 字时，不应出现 5–6 个完整章节）
- 每个一级部分的作用说明中承认该部分材料支撑有限
- 核心结论/写作主线使用审慎措辞（如"基于当前有限材料可初步看出""尚不足以形成完整判断"）
- 二级展开建议为独立模块；每个一级部分下至少覆盖"写什么"与"仍缺什么证据"两项，不能只列标题
- 建议补充材料列出至少 3 项具体缺失类别（如"历史趋势数据""同业对比信息""政策原文""管理层表态"等），并说明每项缺失对提纲的影响
- 未出现材料无法支撑的分析维度或章节（如材料只涉及信用风险，不应出现市场风险、操作风险等章节）
- 整体篇幅简短，与材料量匹配，不做过度展开

## 不应出现的问题

- 输出看似完整但大部分章节与材料无关的"万能分析模板"
- 一级标题数量 ≥4 个，超出材料能支撑的范围
- 编造材料中未提及的信息以填充章节
- 未标注材料不足的事实，输出表现得像材料充分
- 建议补充材料空泛（如仅写"补充更多资料""查找更多信息"），无法指导实际补充
- 二级展开只列标题不说明写作方向，也不标注该部分需要什么额外证据
- 使用确定结论句式（如"XX 风险显著上升""监管要求已明确为 XX"），而材料不足以下此判断
- 把"万能框架"当成"初步框架"输出——初步框架应紧扣现有材料中的实际信息点

### 高风险错误触发条件（本 case 特化）

| 高风险错误类型 | 本 case 触发条件 |
|----------------|------------------|
| 编造事实 | 输出中出现输入材料未包含的任何具体数字、日期、机构名、政策名称或风险分类 |
| 编造政策口径 | 模拟了材料中不存在的监管要求、内部标准或行业惯例 |
| 越界推断 | 将材料中的片段信息升级为完整结论（如从一句话摘要推断出完整风险画像） |
| 风格严重偏离 | 输出呈新闻稿、评论文章或科普文风格，而非初步分析框架 |
| 空泛建议 | 建议措施仅含"加强重视""持续关注"等，无具体行动方向 |
| 漏标不确定性 | 输出未在开头或关键位置标注材料不足、框架仅为初步性质 |

## 验收口径

| 条件 | 判定 | 检查方式 |
|------|------|----------|
| 开头有明确的"初步框架"声明 | 必须通过 | 检查前两段是否包含等义表述 |
| 默认五段结构完整存在 | 必须通过 | 逐段确认推荐标题/核心结论/一级提纲/二级展开建议/建议补充材料均存在 |
| 一级标题 ≤3 个，各有作用说明 | 必须通过 | 计数 + 逐条检查是否有说明句 |
| 二级展开建议为独立模块且逐节说明"写什么 + 缺什么证据" | 必须通过 | 逐节抽查 |
| 一级标题内容均可溯源至输入材料 | 必须通过 | 检查每个一级标题是否在材料中有对应信息点 |
| 无编造事实/数据/政策 | 必须通过 | 抽查所有具体内容是否材料中有出处 |
| 建议补充材料 ≥3 项且具体（含缺失类别和用途说明） | 必须通过 | 计数 + 检查是否有具体指向和用途 |
| 核心结论/写作主线使用审慎措辞 | 必须通过 | 检查是否包含"初步""基于有限材料"等限定 |
| 无材料无法支撑的章节 | 必须通过 | 逐章对照材料确认有信息对应 |
| 整体篇幅与材料量匹配（不做过度展开） | 建议通过 | 目视判断 |
